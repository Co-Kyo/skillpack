skillpack 当前 API 教学

基于 @co-kyo/skillpack@0.1.0 的当前 API 重写。

1skillpack 是什么

skillpack 是一个把结构化 TypeScript 定义打包成 LLM 可执行 Markdown Skill 的构建工具。

你使用 StepDefinition 描述流程步骤，使用控制节点描述步骤内部调度，skillpack 负责校验、排序、渲染并输出 SKILL.md 和 processes/*.md。

2公开包名

@co-kyo/skillpackCLI、defineConfig、createSkillFromModel、buildPipeline
@co-kyo/skillpack-typesStepDefinition、控制节点、task/seq/parallel/mapNode
@co-kyo/skillpack-common校验、拓扑排序、图遍历
@co-kyo/skillpack-validate独立校验 CLI

3安装

npm install -D @co-kyo/skillpack @co-kyo/skillpack-types

4定义 Skill

最简单的入口是 createSkill()，它接收 SkillDefinition 并返回同一对象。

skill.ts
import { createSkill, task, seq, parallel, mapNode } from '@co-kyo/skillpack-types';

const stepParse = {
  id: 'topic-parse',
  title: '主题解析',
  description: '解析调研主题，生成调研框架',
  dependsOn: [],
  graph: task({
    id: 'parse',
    label: '主题解析',
    type: 'agent',
    body: '解析用户输入的调研主题，生成 research-brief.json',
  }),
  reads: [],
  writes: [{ path: '{workDir}/.meta/research-brief.json', description: '调研框架' }],
};

export const skill = createSkill({
  name: 'tech-research',
  title: '前端技术调研',
  description: '从探索到产出的完整调研流程',
  steps: [stepParse],
});

如果你使用 SourceModel 工作流，可以改用 createSkillFromModel(model)，入口在 @co-kyo/skillpack。

5StepDefinition 字段

interface StepDefinition {
  id: string;
  title: string;
  description: string;
  dependsOn: string[];
  graph: ControlNode;
  reads: FileRef[];
  writes: FileRef[];
  barrier?: BarrierDef;
  reuse?: ReuseRule[];
  degrade?: DegradeProtocol;
  body?: string;
  plugins?: string[];
}

graph 是当前版本的核心字段，替代旧版的 schedule。它直接使用递归控制节点，不再使用扁平 nodes/edges/entry。

6控制节点

task()单个任务，type 可为 agent / script / human / subflow
seq()顺序执行一组节点
parallel()并行分支，支持 converge 和 gate
mapNode()从数据源逐项执行同一 worker，支持 maxConcurrency
branch()条件分支
loop()循环执行，支持 maxIterations

并行 + 收敛 + 门禁

parallel()
graph: parallel('explore-batch', '多维度并行探索', [
  task({
    id: 'explore-docs',
    label: 'explore-docs',
    type: 'agent',
    body: '阅读 research-brief.json，产出 docs-findings.json',
  }),
  task({
    id: 'explore-practice',
    label: 'explore-practice',
    type: 'agent',
    body: '阅读 research-brief.json，产出 practice-findings.json',
  }),
], {
  converge: {
    id: 'explore-converge',
    label: 'explore-integrator',
    type: 'agent',
    body: '合并三个维度的发现，产出 consolidated-findings.json',
  },
  gate: {
    rule: '3 agents completed or at most 1 degraded',
    onPass: 'converge',
    onFail: 'degrade',
  },
})

Map / 滚动窗口

mapNode()
graph: mapNode(
  'report-map',
  '章节报告生成',
  '{workDir}/.meta/organized.json#categories',
  task({
    id: 'report-worker',
    label: 'report-{chapter}',
    type: 'agent',
    body: '撰写报告章节 {chapter}，产出 {workDir}/.meta/report/{chapter}.md',
  }),
  3,
)

7配置与 CLI

skillpack.config.ts
import { defineConfig } from '@co-kyo/skillpack';

export default defineConfig({
  skill: './skill.ts',
  outputDir: 'dist/skill',
});
npx skillpack build skillpack.config.ts

CLI 会读取配置、加载 skill、调用 buildPipeline()，并生成 SKILL.md 与 processes/*.md。

8构建流程

  • Validate：校验 StepDefinition 与依赖引用。
  • Resolve：根据 dependsOn 做拓扑排序，解析 {{step:xxx}} 引用。
  • Render：渲染 SKILL.md、processes、align-report 与产物清单。

9Release

公开仓库推送 v* tag 后，GitHub Actions 会构建 npm 包并创建 GitHub Release。

也可以手动运行 Release skillpack workflow，使用 source.zip 和 npm tarball 作为发布产物。
